# HELL ASCENT - 2026-09-30 Release Smoke Test

This is the final short test before publishing Layer One.

## 1. Sync

PowerShell:

```powershell
cd "$HOME\Documents\hell-ascent"
git pull
rojo serve
```

Roblox Studio:

1. Stop Play if it is running.
2. Connect Rojo.
3. Accept the sync.
4. Press Play.

## 2. Check Studio Output

Look for:

```text
[HELL ASCENT] RELEASE READY - required Layer One systems generated
```

If you instead see `RELEASE CHECK FAILED`, do not publish yet. The warning names the missing object.

## 3. One complete run

Only verify these release blockers:

- Timer starts after the character is ready.
- Sprint works.
  - PC: Shift
  - Mobile: 走る button
- First seal wakes THE WARDEN.
- Stage 1 Warden stops when directly observed.
- Second seal makes the Warden continue moving while observed, but slower.
- ASH RIFT is unavailable before 2 seals and usable after 2 seals if HP > 25.
- Soul Anchor heals HP and restores stamina.
- Death costs 20 seconds and respawns at the latest Soul Anchor.
- Third seal starts FINAL RUN.
- FINAL RUN shows Black Gate and Warden distance.
- Black Gate completes the layer.
- End screen shows clear time / deaths / BEST.
- RETRY starts a fresh run.

## 4. Mobile sanity check

Use Studio device emulation or a phone.

Verify:

- 走る button does not overlap the jump button.
- ProximityPrompt is tappable.
- Top HUD remains readable.
- FINAL RUN panel does not cover the center of the screen.
- Direction arrows remain understandable while rotating the camera.

## 5. Publish

If the checks above pass:

1. Stop Play.
2. Save the place if Studio asks.
3. Publish the current place to the HELL ASCENT experience.
4. Launch the published experience once, preferably on a phone.
5. Confirm the first seal, sprint, Warden and Black Gate still work.

## Release rule

Do not add new gameplay systems after this smoke test.

Only fix:
- crashes/errors,
- progression blockers,
- unusable mobile controls,
- impossible Warden balance,
- broken publishing/sync issues.

Everything else can wait for the next update.
