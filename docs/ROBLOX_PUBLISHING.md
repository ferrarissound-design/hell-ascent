# HELL ASCENT - Roblox Publishing Pack

Use this page when publishing the 2026-09-30 Layer One release candidate.

## Experience name

**HELL ASCENT**

Optional subtitle for thumbnails / description:

**LAYER ONE: ASHEN VERGE**

## Recommended release configuration

For the first public release:

- **Max players: 1**
- Supported input: keyboard/mouse, touch, gamepad
- Mobile support: enabled
- Streaming: disabled in the Rojo project for release stability
- Public release only after one complete Studio run
- Keep this first version solo. The current Warden is a single shared enemy and multiplayer balancing is intentionally deferred.

## Full description - English

**HELL ASCENT**

You awaken in the first layer of Hell: **ASHEN VERGE**.

Your soul has ten minutes left.

Break all three Soul Seals and escape through the Black Gate.

But every broken seal changes the world and unleashes **THE WARDEN**.

At first, watching it can stop it.
After the second seal, your gaze only slows it.
After the third seal, looking at it no longer helps.

**RUN.**

### Features

- 10-minute escape runs
- Three Soul Seals
- A Warden that reacts to your gaze
- Stamina sprint
- Soul Anchor checkpoints
- Risk/reward ASH RIFT shortcut
- FINAL RUN escape sequence
- Clear time, deaths and session personal best
- Keyboard, touch and gamepad controls

This is only the first layer.

## Content questionnaire notes

Answer the current Roblox questionnaire based on what is actually present in the published build.

Current build contains:

- dark fantasy / Hell imagery
- a hostile humanoid monster
- player damage and death
- red screen damage feedback
- lava / environmental death hazards

Current build does **not intentionally include**:

- visible blood
- gore or dismemberment
- realistic injury detail
- firearms
- sexual content
- gambling
- alcohol or drug gameplay

If the questionnaire wording differs from these notes, answer from the actual game rather than forcing these notes onto a different question.

## Icon direction

Use a square image with:

- THE WARDEN centered or slightly off-center
- almost-black silhouette
- single vertical red face slit
- Black Gate glowing behind it
- minimal text
- only the title **HELL ASCENT**
- strong readability at small mobile size

Avoid showing unrelated demons or weapons that do not exist in the game.
