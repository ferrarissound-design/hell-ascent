# HELL ASCENT - Screenshot Capture Plan

Capture these during tomorrow's final Studio test. Three good screenshots are enough for the first release.

## Shot 1 - The Warden

Best moment:
- exactly 1 Soul Seal broken
- Warden is at medium distance
- player camera is looking directly at it
- Warden has stopped because it is observed

Frame:
- Warden near center
- red face slit clearly visible
- keep some environment visible
- avoid UI covering the face

Purpose:
- communicates the game's unique gaze mechanic.

## Shot 2 - FINAL RUN

Best moment:
- third seal has just been broken
- FINAL RUN HUD is visible
- Black Gate visible ahead
- Warden behind or to the side if possible

Purpose:
- communicates the escape climax.

## Shot 3 - ASH RIFT

Best moment:
- two seals broken
- ASH RIFT glowing
- interaction prompt visible
- Warden not blocking the object

Purpose:
- shows that route decisions exist beyond simply walking forward.
